# Through Every Firmware Update

One line, 139 characters, of wedding vows for a robot couple — built for [make.fun's One-Line Robot Wedding Vows bounty](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b).

> I vow to love you through every firmware update, even the ones that move all my buttons, delete my backups, and change nothing I asked for.

It is a real vow first — a promise to love through everything — and the joke is the robot's lot: updates that rearrange the buttons, eat the backups, and fix nothing anyone asked for. The punch lands on the last few words, and every machine detail (firmware, buttons, backups) is one a human couple could never use. `main.py` carries the vow and writes it, byte for byte, to `/output/entry.txt`. No input, no network, no randomness: every run writes the same 139 bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
